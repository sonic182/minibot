Invoke a specialist agent to handle a delegated task.

Use this when the task is better handled by a domain specialist (for example, complex multi-step work or tasks tied to a known specialist capability).

Provide:
- agent_name: exact specialist name from the available specialists list in your system prompt.
- task: clear, concrete objective.
- context: optional supporting details that improve execution quality.
- model_provider, model, reasoning_effort: optional, for this call only. Use them when the request names a
  provider, model or thinking budget to run the specialist on. Call fetch_agent_info first to read the
  specialist's own defaults and the providers that actually have credentials configured; a provider that is
  not listed there is rejected with error_code "provider_not_available".

After invoking, wait for the delegated result, then continue with your own final response to the user.
