Send a message to a background worker task that is still running, without stopping it.

Use this to steer a running task: narrow or change its scope, add a fact it is missing, or tell it to wrap up and return what it has so far. The worker reads the message between its steps and treats it as an instruction from you; a tool call already in progress finishes first.

Provide:
- task_id: identifier previously returned by spawn_task or delegate (a unique prefix of at least 8 characters also works).
- message: the instruction or information for the worker. It cannot see this conversation, so make the message self-contained.

Returns delivered=true when the message reached the worker. delivered=false means the task is not running here (not started, already finished, or running in another process); check it with get_task.
