Read the MiniBot documentation that ships with this installed version. Call it with no arguments to list the pages, with `query` to search every page for words such as a config key or tool name (returns matching lines per page), or with `page` to read one page in full. Config sections are expanded to their field reference. Use it when the user asks how a MiniBot feature, config key, tool, channel, skill or agent works. It describes how MiniBot works, not what this instance has enabled; use get_settings for that. If it returns `docs_unavailable`, the documentation is not bundled in this install.
